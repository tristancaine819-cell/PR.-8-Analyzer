NumPy Analyzer

A menu-driven Python application that helps users perform various NumPy operations such as array creation, mathematical calculations, array manipulation, searching, sorting, filtering, and statistical analysis.

📌 Features
1. Create NumPy Arrays
Create 1D, 2D, or multidimensional arrays
Initialize arrays with user-defined values
Display created arrays
2. Mathematical Operations
Addition
Subtraction
Multiplication
Division
Exponentiation
Other NumPy-based arithmetic operations
3. Combine or Split Arrays
Concatenate arrays
Stack arrays vertically or horizontally
Split arrays into multiple parts
Reshape arrays when required
4. Search, Sort, and Filter
Search for specific elements
Sort arrays in ascending or descending order
Apply filtering conditions
Retrieve matching values efficiently
5. Aggregates and Statistics
Sum of elements
Mean
Median
Maximum and Minimum values
Standard Deviation
Variance
Other statistical operations
